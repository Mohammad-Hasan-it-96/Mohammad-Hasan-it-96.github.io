# الصور / Images

الصفحة تشتغل تماماً بدون صور — كل مشروع بيظهر بخلفية متدرّجة فيها أول حرف من اسمه.
لما تحطّ صورة بالاسم الصحيح، بتاخد مكان الخلفية تلقائياً. ما في شي لازم تعدّلو بالكود.

The site works fine with no images at all — each project falls back to a gradient
placeholder. Drop a file with the right name and it takes over automatically.

---

## 1. الصورة الشخصية / Profile photo

```
images/profile.jpg      ← أو profile.png
```

- نسبة عمودية تقريباً **1 : 1.14** (مثلاً 700 × 800 بكسل)
- الوجه بالنص، خلفية بسيطة، إضاءة جيدة
- إذا ما حطيت صورة، بتظهر أحرف **MH** بتدرّج لوني — شكلها منيح كمان

## 2. صور المشاريع / Project screenshots

الملفات بتنحط هون:

```
images/projects/<id>.jpg      ← أو .png
```

نسبة **16 : 9** أفقية، يفضّل **1600 × 900** بكسل. الأسماء لازم تكون بالضبط:

### نصائح للسكرينات

**تطبيقات الموبايل (Flutter)** — الكرت أفقي 16:9، فصورة موبايل واحدة عمودية رح
تبين ضايعة بالنص. الأفضل: حطّ **2 أو 3 شاشات جنب بعض** على خلفية لون واحد
(داكن أحسن، قريب من `#0d1220`)، أو صورة للتطبيق شغّال على جهاز حقيقي.
الشاشة الأقوى عادةً: شاشة البيع / الطلب، مو شاشة تسجيل الدخول.

**أنظمة Laravel** — سكرين للوحة التحكّم أو صفحة التقارير، بعرض ديسكتوب كامل.
انتبه للبيانات: إذا فيها أسماء زبائن أو أرقام حقيقية، بدّلها بأسماء وهمية قبل التصوير.

**المشاريع العتادية (الأذان، المنزل الذكي، الدرون)** — هون الصورة الحقيقية أقوى
من أي شي: الدارة وهي مركّبة، اللوحة، الدرون وهو طاير أو بالورشة. حتى لو صورة
موبايل عادية، هي بتعطي مصداقية ما بتعطيها أي واجهة برمجية.

**لو ما عندك صورة لمشروع** — خلّيه بدون صورة. الخلفية البديلة نظيفة، وأحسن
بكتير من صورة ضعيفة أو مقصوصة غلط.
